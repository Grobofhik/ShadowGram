# Создание профиля

## Что хранит профиль

У профиля есть:

- имя
- рабочая папка
- proxy
- `api_id` / `api_hash`
- device model
- system version
- app version
- `system_lang_code`
- `lang_pack`
- `lang_code`
- заметки
- AI prompt

## Где создаётся

По умолчанию профиль создаётся внутри:

```text
farms/<active_farm>/accounts/<profile_name>/
```

Эту папку можно изменить вручную, но стандартный путь лучше не ломать.

## Как создать

Из главного окна:

1. Нажми `Создать профиль`.
2. Укажи имя.
3. Проверь рабочую папку.
4. При необходимости заполни proxy.
5. При необходимости задай свои `api_id/api_hash`.
6. Сохрани профиль.

## API-ключи

При сохранении логика такая:

- если у профиля заданы `api_id/api_hash`, используются они
- иначе берутся `default_tg_api_id/default_tg_api_hash` из настроек

Пустой профиль без API-ключей можно создать, но сессию потом создать не получится, пока ключи не появятся.

## Что делать сразу после создания

Рекомендуемо:

1. Открыть карточку профиля.
2. Проверить proxy.
3. Запустить `Авторизовать (Войти)`.
4. После создания сессии прогнать `Проверка сессии`.
