# 👤 Создание и управление профилями

Профиль в ShadowGram — это полностью изолированное окружение для вашего Telegram-аккаунта. Каждый профиль содержит уникальную сессию, базу данных, привязанный прокси и персональные настройки цифрового отпечатка.

---

## 🛠 Процесс создания профиля

Для добавления нового аккаунта перейдите на главную страницу (вкладка **Аккаунты**) и используйте нижнюю панель "Добавить новый профиль".

### 1. Системное имя профиля
Поле **"Имя профиля"** используется исключительно для внутренней идентификации. 
- Рекомендуется использовать структурированные названия, например: `Bot_Support_01`, `Main_Admin`, `Client_Forwarder`.
- Это имя никак не влияет на отображаемое имя аккаунта в самом Telegram.

### 2. Изолированная директория (Workdir)
Это самый критичный этап создания. В поле **"Путь к Tdata/Папке"** вы должны указать директорию, где будут храниться локальные файлы сессии.
- **Новая сессия:** Укажите путь к новой пустой папке. При первом запуске ShadowGram сгенерирует новый файл `.session` и попросит вас авторизоваться по номеру телефона (через модуль `Получить код` или напрямую).
- **Существующая сессия:** Если у вас уже есть файл сессии Pyrogram/Hydrogram, укажите путь к папке с этим файлом. ShadowGram автоматически подхватит его.
> ⚠️ **Категорически запрещено** использовать одну и ту же директорию для двух разных профилей. Это приведет к повреждению базы данных SQLite.

### 3. Настройка Proxy (Крайне рекомендуется)
Для безопасной работы каждый аккаунт должен иметь собственный IP-адрес. Вставьте ссылку в формате:
`http://user:password@ip:port` или `socks5://user:password@ip:port`
- Используйте встроенную кнопку **Проверить прокси** (иконка радара) перед созданием. ShadowGram выполнит пинг и проверит валидность узла.

### 4. API Ключи
Telegram требует наличие `api_id` и `api_hash` для работы. 
- По умолчанию вы можете оставить эти поля пустыми. В таком случае ShadowGram подставит глобальные ключи, заданные во вкладке **Настройки**.
- Если вы хотите использовать уникальные ключи для конкретного аккаунта (для снижения риска каскадного бана), укажите их здесь.

---

## 🔄 Жизненный цикл профиля

После создания профиль появится в таблице аккаунтов. 
- **Статус "Неизвестно":** Сессия еще не проверена. Используйте модуль **"Проверка сессии"**, чтобы ShadowGram связался с серверами Telegram и подгрузил аватарку, ID и статус (Online/Banned).
- **Редактирование:** Вы можете в любой момент изменить прокси или имя, нажав кнопку с шестеренкой рядом с аккаунтом.
