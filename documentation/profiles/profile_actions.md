# Действия с профилями

## Основные действия в списке

На странице `Аккаунты` доступны:

- поиск по имени, пути, proxy, device, заметкам, AI prompt
- открытие карточки профиля
- авторизация сессии
- запуск/остановка задач
- массовая проверка proxy
- массовая очистка cache

## Авторизация

Кнопка `Авторизовать (Войти)` открывает мастер создания сессии.

В мастере:

- имя `.session` подставляется из имени профиля
- путь сохранения подставляется из рабочей папки профиля
- проверяется конфликт по имени файла
- можно выбрать `Hydrogram` или `Telethon`
- показываются понятные логи по шагам
- есть ввод кода
- при `2FA` есть ввод пароля с повторной попыткой при ошибке
- есть `Отмена` на любой стадии

## Массовые действия

В разных частях UI есть массовые операции:

- массовое создание профилей
- массовая раздача proxy из pool
- массовая очистка proxy
- запуск модулей по выбранным аккаунтам

## Работа с файлами аккаунта

В папке профиля обычно лежат:

- `.session`
- `avatar.jpg`
- локальный cache Telegram/клиента

При включённой опции `auto_clean_cache` cache чистится при выходе из приложения.

## Когда профиль считается готовым

Минимально:

- задан валидный `api_id/api_hash`
- настроен proxy, если он нужен
- создана рабочая `.session`
