# ⚙️ Действия с профилем

После создания аккаунта в таблице, вам доступен ряд действий для управления его состоянием. 

---

## 🎛 Основные операции

Кликните правой кнопкой мыши по аккаунту в таблице (или используйте кнопки в строке), чтобы вызвать контекстное меню.

### 1. ✏️ Редактирование профиля (Шестеренка)
Открывает форму редактирования, где вы можете:
*   **Изменить прокси:** Если старый прокси-сервер "умер", вставьте новый. ShadowGram автоматически применит новые сетевые настройки при следующем запуске модуля для этого аккаунта.
*   **Изменить имя:** Переименуйте аккаунт для более удобной навигации в таблице.

### 2. 🗑 Удаление профиля (Корзина)
Удаление аккаунта из базы данных ShadowGram.
*   **Внимание:** При удалении из таблицы, системная папка (Workdir) с сессией на жестком диске **НЕ удаляется** по соображениям безопасности. Если вам нужно полностью стереть данные, удалите папку вручную через Проводник вашей ОС.

### 3. 📂 Открыть рабочую директорию
Позволяет быстро открыть папку, в которой хранятся файлы `.session`, `.config` и логи конкретного аккаунта. Полезно для ручного бекапа отдельной сессии.

## 📊 Статусы аккаунтов

Таблица отображает актуальный статус профиля (цветовой индикатор):
*   🟢 **OK:** Аккаунт жив, сессия валидна, ограничений нет.
*   🟡 **SpamBlock:** Аккаунт жив, но на него наложены ограничения SpamBot (не может писать первым). Модули чтения и подписок работать будут.
*   🔴 **Banned:** Аккаунт удален Telegram (Session Revoked) или заблокирован номер. Работать с ним больше нельзя.
*   ⚪ **Unknown:** Статус неизвестен. Запустите модуль "Проверка сессии" для обновления.

## 📝 Множественный выбор (Batch Actions)
Вы можете выделить сразу несколько аккаунтов, используя чекбоксы (квадратики слева от имени). Это позволяет вам запускать один и тот же модуль параллельно для всех выбранных профилей в один клик!
