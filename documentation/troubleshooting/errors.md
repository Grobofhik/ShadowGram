# Ошибки и решения

## `The api_id/api_hash combination is invalid`

Telegram отверг пару `api_id/api_hash`.

Проверь:

- ключи профиля
- глобальные `default_tg_api_id/default_tg_api_hash`
- лог auth-окна, какой `API ID` реально использовался

Если проект ушёл в fallback API, это временный резерв, не гарантия.

## `API_ID_PUBLISHED_FLOOD`

Telegram считает пару опубликованной/злоупотребляемой.

Решение:

- использовать свои ключи из `my.telegram.org`
- не полагаться на fallback API

## Код не приходит

Проверь:

- жив ли proxy
- не завис ли туннель `gost`
- правильный ли номер у аккаунта
- не был ли код уже доставлен на другое устройство

Если процесс завис, жми `Отмена` и запускай auth заново.

## Неверный пароль `2FA`

Теперь auth не падает сразу. Можно ввести пароль повторно или отменить процесс.

## Не создаётся сессия через HTTP/HTTPS proxy

Скорее всего:

- не установлен `gost`
- proxy мёртв
- proxy требует формат, который проект не смог разобрать

## `No module named telethon`

Установи `telethon`.

```bash
pip install telethon
```

## `No module named requests`

Установи `requests`.

```bash
pip install requests
```

## Пустой список аккаунтов

Проверь:

- активную ферму
- `farms/<farm>/config.json`
- реально ли профили есть в этой ферме

Плашка пустого состояния должна показываться только когда аккаунтов реально нет.

## Не работает модуль с proxy

Проверь:

- формат proxy
- доступность proxy
- тип proxy: SOCKS работает напрямую, HTTP/HTTPS часто идут через `gost`
- не превышен ли timeout

## Не открывается dashboard

Возможна нехватка `pyqtgraph` или другой UI-зависимости.

```bash
pip install pyqtgraph
```
