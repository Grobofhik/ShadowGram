# 🛠 Устранение неполадок (Troubleshooting & Errors)

При работе с большим количеством аккаунтов вы неизбежно столкнетесь с ошибками Telegram API или системными сбоями. В этом разделе собраны самые популярные проблемы и пути их решения.

---

## ❌ Ошибки Telegram API (Hydrogram)

### 1. `FloodWait (X seconds)`
Самая распространенная ошибка. Telegram сообщает, что вы выполняете действия слишком быстро и наложил временный лимит (Мут) на `X` секунд.
*   **Причина:** Слишком агрессивные настройки задержек (Delay) или исчерпание суточного лимита на подписки/инвайты.
*   **Решение:** ShadowGram автоматически перехватывает эту ошибку и ставит процесс на паузу на указанное время. Просто подождите. Для предотвращения в будущем — увеличьте задержки.

### 2. `UserDeactivated` / `UserDeactivatedBan`
Сессия отозвана (Revoked) сервером Telegram.
*   **Причина:** Аккаунт был навсегда заблокирован за спам, либо пользователь завершил сессию с другого устройства.
*   **Решение:** Восстановить сессию невозможно. Удалите профиль из таблицы (статус `BANNED`) и зарегистрируйте новый аккаунт.

### 3. `AuthKeyUnregistered` / `SessionRevoked`
Ваш локальный файл `.session` больше не валиден.
*   **Причина:** Аналогично пункту выше (бан или принудительный выход из аккаунта).
*   **Решение:** Удалите профиль.

### 4. `PeerFlood`
Аккаунт получил теневой бан (Shadowban) на взаимодействие с пользователями не из списка контактов.
*   **Причина:** Пользователи нажимали кнопку "Spam" на ваши сообщения.
*   **Решение:** Напишите `@SpamBot` в Telegram, чтобы узнать срок действия ограничений (SpamBlock). В ShadowGram статус аккаунта можно проверить, он загорится желтым.

## ⚙️ Системные ошибки ShadowGram

### 1. `SQLite Database is Locked`
*   **Причина:** Несколько процессов ShadowGram пытаются одновременно получить доступ к одной и той же сессии/папке. (Например, вы открыли приложение дважды или указали одну папку для двух профилей).
*   **Решение:** Убедитесь, что каждый профиль имеет строго уникальную папку `Workdir`. Перезапустите ShadowGram.

### 2. `ProxyError: Connection Timeout` / `SOCKSHTTPSConnectionPool`
*   **Причина:** Введенный прокси не отвечает или сервер прокси заблокировал ваше подключение.
*   **Решение:** Откройте профиль, нажмите кнопку "Радар", чтобы проверить прокси. Замените его на рабочий.

### 3. Не приходят уведомления в системный Трей
*   **Причина:** Ваш Linux (например, `xfce` или `i3` без `dunst`) или Windows настроен на подавление уведомлений.
*   **Решение:** Проверьте настройки "Фокусировки внимания" (Focus Assist) в Windows или убедитесь, что установлен Notification Daemon в Linux.
