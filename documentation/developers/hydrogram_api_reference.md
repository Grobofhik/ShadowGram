# Hydrogram в проекте

Это не полный справочник Hydrogram. Это короткая памятка по тому, как ShadowGram его использует.

## Где используется

- создание сессий
- запуск модулей через `BaseModule.init_client()`
- проверка сессий
- реакции, просмотры, privacy и прочие Telegram-действия

## Что важно для интеграции

- session-файл ищется в рабочей папке аккаунта
- `api_id/api_hash` берутся из профиля или глобальных настроек
- proxy могут быть SOCKS напрямую или HTTP/HTTPS через `gost`
- часть действий использует raw API

## Практический минимум

При создании клиента важны:

- путь к session
- `api_id`
- `api_hash`
- `device_model`
- `system_version`
- `app_version`
- `lang_code`
- `system_lang_code`

## Ограничения

- если session отсутствует, модуль не стартует
- если proxy битый, клиент не подключится
- если API-пара невалидна, auth/session flow упадёт до кода
