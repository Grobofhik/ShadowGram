# ServerGram

## Что это

Страница `Сервер` — клиент к удалённому серверу ServerGram.

Она умеет:

- сохранить IP и port сервера
- сохранить API ID/API Hash для удалённой стороны
- проверить доступность сервера
- отправить архив с выбранными сессиями
- запустить выбранный модуль на сервере

## Что нужно заполнить

- `server_ip`
- `server_port`
- `api_id`
- `api_hash`

Эти поля сохраняются в конфиг проекта.

## Проверка соединения

На странице есть ping/проверка соединения. Сначала делай её, потом уже импорт сессий и запуск.

## Как отправляются сессии

Приложение собирает архив с выбранными `.session` и отправляет его на API сервера.

Практический смысл:

- локально ведёшь профили и сессии
- на удалённый сервер отправляешь только нужный набор

## Ограничения

- страница не заменяет локальный модульный движок
- без доступного API сервера запуск не сработает
- если локальные сессии отсутствуют или битые, на сервер отправлять нечего
