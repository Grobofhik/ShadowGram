# 🖥 Управление сервером (ServerGram)

Вкладка **Сервер** предоставляет мощный интерфейс для управления удаленными фермами и мониторинга системных ресурсов. ShadowGram может выступать в роли центрального хаба (Master) для управления удаленными машинами (Nodes).

---

## 🔗 Подключение к серверу

Для начала работы вам необходимо настроить соединение с удаленным сервером:

### 1. Настройка SSH / API
В панели настроек сервера укажите:
- **IP / Host:** Адрес вашего удаленного сервера (например, `192.168.1.100` или `server.domain.com`).
- **Порт:** Стандартный SSH порт (обычно `22`) или кастомный порт API демона ServerGram.
- **Пользователь и Пароль:** Учетные данные для доступа. Для большей безопасности рекомендуется использовать SSH-ключи.

### 2. Подключение
После ввода данных нажмите кнопку **"Подключиться"**. Система выполнит аутентификацию и загрузит базовые метрики сервера. В правой панели появится статус `Connected` (зеленый индикатор).

---

## 📊 Мониторинг ресурсов

В реальном времени ServerGram отображает загрузку критических узлов удаленной машины:
- **CPU (Процессор):** Текущая утилизация в процентах. Рекомендуется не превышать 85% во избежание троттлинга сессий.
- **RAM (Оперативная память):** Использовано / Всего. Каждая сессия Hydrogram потребляет около 30-50 МБ ОЗУ. Учитывайте это при расчете количества аккаунтов.
- **Диск:** Заполненность жесткого диска. Файлы кэша (особенно медиа) могут быстро занять свободное пространство.

---

## 🕹 Управление процессами (Nodes)

Нижняя панель предоставляет терминал и список активных процессов:
- **Запуск сценариев:** Вы можете выбрать конкретный модуль и запустить его на сервере для выбранных аккаунтов. ShadowGram автоматически сериализует задачу и отправит ее демону.
- **Остановка:** В случае зависания модуля или чрезмерного потребления ресурсов, вы можете принудительно убить процесс (Kill Signal).
- **Синхронизация Tdata:** Нажмите **"Синхронизировать"**, чтобы скачать актуальные `.session` файлы с сервера на локальную машину для создания бекапа.

> 🛠 *Примечание разработчика:* Функция управления кластерами в данный момент находится на стадии бета-тестирования. Убедитесь, что версии ShadowGram на локальной машине и сервере совпадают.
