# 🚀 Добро пожаловать в ShadowGram Wiki

**ShadowGram** — это передовая, модульная и высокопроизводительная система для профессионального управления сетью Telegram-аккаунтов. Построенный на базе современного асинхронного движка `asyncio` и библиотеки `hydrogram`, данный комплекс предоставляет пользователям полный спектр инструментов для автоматизации действий, масштабирования сетей и безопасной работы.

Проект был разработан с учетом самых строгих требований к безопасности, обеспечивая максимальную изоляцию данных каждой сессии. Сочетание интуитивно понятного графического интерфейса с мощной архитектурой плагинов делает ShadowGram безальтернативным решением как для энтузиастов, так и для крупных SMM-агентств.

---

## 💎 Ключевые преимущества архитектуры

### 🗂 Глубокая изоляция данных (Multi-Accounting)
ShadowGram использует архитектуру независимых рабочих директорий (Workspaces). Каждая сессия Telegram полностью изолирована:
- Уникальные кэши и локальные базы данных.
- Строгая привязка конкретных прокси-серверов.
- Индивидуальные настройки цифровых отпечатков (Device Fingerprinting).

### 🛡 Встроенная безопасность и Anti-Ban системы
В приложении реализован комплекс мер для снижения риска блокировки аккаунтов (Anti-Ban):
1.  **Индивидуализация сессий:** Автоматическая генерация параметров `device_model`, `system_version` и `app_version` на основе алгоритмов.
2.  **Умные задержки (Smart Delays):** Все действия имитируют поведение реального человека благодаря рандомизации таймингов в модулях.
3.  **Изолированное подключение:** Поддержка IPv4 и IPv6 прокси (HTTP/SOCKS) для маскировки реального IP-адреса.

### 🧩 Система динамических модулей
Автоматизация — это ядро ShadowGram. Встроенные модули могут запускаться параллельно в фоне для множества аккаунтов. Вы можете использовать:
- **Auto Reactor & Commenter:** Взаимодействие с контентом для прогрева или повышения метрик.
- **Privacy Guard:** Настройка параметров приватности за 1 клик.
- **Smart Warmer:** Интеллектуальный прогрев аккаунтов через диалоги с ботами и чтение каналов.

### 📡 ServerGram — Централизованное управление
ShadowGram может выступать как клиент для управления удаленными фермами. Встроенная вкладка `Server` позволяет:
- Подключаться к удаленным машинам.
- Отправлять массовые команды на запуск модулей.
- Мониторить состояние серверов в реальном времени.

## 🚦 Как начать работу?

Ваш путь к полноценной автоматизации состоит из 3 простых шагов:

1.  **Настройте глобальные параметры:** Перейдите во вкладку [Настройки](settings/global_settings.md), чтобы задать базовые API ключи и защитить приложение ПИН-кодом.
2.  **Добавьте профиль:** Изучите инструкцию по [созданию первого профиля](profiles/create_profile.md).
3.  **Запустите модуль:** Выберите аккаунт, перейдите в [Модули](modules/README.md) и активируйте, например, **Privacy Guard** для защиты вашего профиля.

> **Важно:** Всегда используйте надежные приватные IPv4 прокси для работы с большим количеством аккаунтов!
