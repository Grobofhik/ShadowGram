# Старт

## Что такое ShadowGram

ShadowGram — локальное desktop-приложение для ведения Telegram-фермы. Основные сущности:

- `ферма` — набор аккаунтов и настроек
- `профиль` — отдельный аккаунт с рабочей папкой
- `сессия` — файл Telegram `.session`
- `модуль` — плагин автоматизации

## Как устроено хранение

- активная ферма берётся из `active_farm.txt`
- её конфиг копируется в корневой `config.json`
- профили лежат в `farms/<farm>/accounts/`

Пример:

```text
farms/
  Default/
    config.json
    accounts/
      acc1/
        acc1.session
        avatar.jpg
      acc2/
        telethon_main.session
```

## Навигация по UI

- `Аккаунты` — основной рабочий экран
- `Создать` — быстрое создание профиля
- `Таблица` — плотная табличная работа
- `Модули` — запуск плагинов по аккаунтам
- `Доп. сервисы` — auth/session/API/converter-инструменты
- `Настройки` — API, AI, proxy pool, backup, безопасность, фермы

## Базовый поток работы

1. Создать или импортировать ферму.
2. Создать профиль.
3. Заполнить proxy и API-ключи.
4. Создать сессию кнопкой `Авторизовать (Войти)`.
5. Проверить сессию.
6. Запускать нужные модули.

## Что важно понять сразу

- профиль без валидной сессии не сможет работать в Telegram-модулях
- HTTP/HTTPS proxy для части операций требуют `gost`
- fallback API есть, но не заменяют свои `api_id/api_hash`
- backup может содержать чувствительные `.session` файлы
