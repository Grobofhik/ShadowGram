# 📝 Сценарии (Scenarios)

Модуль "Сценарии" (Scenario Window) — это мощный инструмент оркестрации в ShadowGram, позволяющий вам выстраивать сложные цепочки действий из нескольких модулей.

---

## 🎯 Назначение

Обычный запуск модулей подразумевает выполнение одной конкретной задачи (например, только просмотр постов). Сценарии позволяют объединять модули в последовательности (Pipelines), которые выполняются друг за другом автоматически без вашего участия.

**Пример сценария для нового аккаунта:**
1. `Set Avatar` (Установить фото) -> 2. `Privacy Guard` (Закрыть настройки приватности) -> 3. `Smart Warmer` (Прогрев) -> 4. `Mute Notifications` (Отключить звук).

## ⚙️ Как это работает

1. Перейдите во вкладку **Сценарии** на боковой панели.
2. Нажмите **"Создать новый сценарий"**.
3. Из списка доступных модулей (слева) перетащите нужные плагины в цепочку выполнения (справа) или добавляйте их кликом.
4. Настройте параметры каждого блока (модуля) индивидуально прямо в конструкторе сценария.
5. Сохраните сценарий (он запишется в файл `.json` в папке `scenarios/`).
6. Выберите нужные аккаунты и нажмите **Запуск**.

## 🔄 Параллелизм и Изоляция

ShadowGram обрабатывает сценарии асинхронно:
- Если вы выбрали 100 аккаунтов, каждый из них начнет выполнять свой экземпляр сценария независимо.
- Если аккаунт №1 закончил устанавливать аватарку за 5 секунд, он сразу перейдет к следующему шагу (Warming), не дожидаясь, пока аккаунт №2 закончит скачивать фото из-за медленного прокси.

## 💡 Советы по использованию

- **Логические паузы:** Вы можете добавлять модуль `Sleep` (Пауза) между агрессивными действиями в сценарии, чтобы имитировать раздумья пользователя.
- **Обработка ошибок:** Если один из модулей в цепочке завершается с критической ошибкой (например, FloodWait), аккаунт может прервать выполнение всего сценария, чтобы не усугублять блокировку. Следите за Консолью логов (Console Output).
