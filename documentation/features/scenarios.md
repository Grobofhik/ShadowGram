# Сценарии использования

## 1. Новая ферма с нуля

1. Создай новую ферму в `Настройки -> Фермы`.
2. Укажи глобальные `default_tg_api_id/default_tg_api_hash`.
3. Добавь proxy pool.
4. Создай профили.
5. На каждом профиле создай сессию.
6. Запусти `Проверка сессии`.

## 2. Быстрый импорт готовой фермы

1. Импортируй ZIP backup.
2. Перезапусти или обнови список.
3. Проверь, что у профилей есть `.session`.
4. Прогоняй `Проверка сессии`.

## 3. Авторизация с HTTP proxy

1. Укажи HTTP/HTTPS proxy в профиле.
2. Убедись, что установлен `gost`.
3. Запусти `Авторизовать (Войти)`.
4. Следи за логами в окне auth.

Если `gost` не найден или proxy мёртв, auth сломается ещё до кода.

## 4. Прогрев и контент

Типичный порядок:

1. `Проверка сессии`
2. `Privacy Guard`
3. `Mute All`
4. `Умный прогрев`
5. `Авто-Реакции` / `AI-комментер` / `Нейрокомментинг`

## 5. Массовая подписка

1. Подготовь список ссылок.
2. Запусти `Масс-Фолловер`.
3. Держи умеренные задержки.
4. Не запускай много аккаунтов на один и тот же список слишком агрессивно.

## 6. Удалённый запуск через ServerGram

1. Открой страницу `Сервер`.
2. Укажи IP/port/API.
3. Проверь ping.
4. Отправь сессии на сервер.
5. Выбери модуль и запусти.

Это не заменяет локальные сессии в проекте, а дополняет локальный режим.
