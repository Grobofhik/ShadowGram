# Проверка сессии

Проверяет рабочесть аккаунта и обновляет часть метаданных.

## Что делает

- проверяет, что сессия открывается
- проверяет бан/ограничения через `@SpamBot`
- скачивает аватар профиля
- проверяет часть privacy-настроек
- обновляет локальные поля аккаунта

## Когда запускать

- сразу после создания сессии
- после импорта старых аккаунтов
- перед массовым запуском других модулей
