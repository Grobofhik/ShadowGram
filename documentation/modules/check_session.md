# 🩺 Check Session (Проверка сессии)

Базовый модуль для валидации и обновления информации о ваших профилях.

---

## 🎯 Назначение
Используется для проверки того, жив ли аккаунт, не вылетел ли он из сессии (Session Revoked) и обновления данных (Аватарка, Имя, Номер телефона) в таблице ShadowGram.

## ⚙️ Как это работает
Модуль пытается выполнить легкий API запрос `GetMe()` к серверам Telegram. 
- Если ответ успешен, он скачивает аватарку в кэш и обновляет UI.
- Если возвращается ошибка `UserDeactivated`, статус аккаунта помечается как `BANNED`.

## 🛠 Настройки
Модуль не требует специфических настроек. Просто выберите нужные аккаунты и нажмите Запуск.

## 💡 Советы по использованию
- Запускайте этот модуль раз в неделю для всей фермы, чтобы актуализировать базу данных и удалять заблокированные аккаунты.
