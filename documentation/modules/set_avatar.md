# 🖼 Set Avatar (Установка фото)

Модуль для массовой установки фотографий профиля для ваших ферм.

---

## 🎯 Назначение
Делает сетку аккаунтов визуально привлекательной и человечной. Аккаунты без аватарок чаще подвергаются ручной модерации и удаляются админами из чатов.

## ⚙️ Как это работает
Вы указываете папку с изображениями на вашем ПК. Модуль:
1. Берет случайную или последовательную картинку из папки.
2. Обрезает ее до нужного соотношения сторон (1:1).
3. Загружает на сервер Telegram и устанавливает как Main Profile Photo.

## 🛠 Настройки
*   **Images Folder:** Путь к папке с фотографиями (`.jpg`, `.png`).
*   **Mode:** `Random` (случайное фото) или `Sequential` (по порядку).
*   **Delete old avatars:** Опция удаления предыдущих фотографий профиля.

## 💡 Советы по использованию
- Собирайте уникальные фотографии (без вотермарок), чтобы избежать банов за спам-профили.
- Не загружайте фотографии знаменитостей.
