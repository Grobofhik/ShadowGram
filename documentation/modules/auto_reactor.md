# Авто-реакции

Ставит реакции под постами в канале.

## Параметры

- `channel_url`
- `posts_count`
- `reaction_chance`

## Особенности

- сам пытается определить разрешённые реакции
- поддерживает кастомные emoji, если канал их разрешает
- если список реакций недоступен, использует безопасные fallback-реакции
