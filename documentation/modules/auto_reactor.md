# ❤️ Auto Reactor (Авто-реакции)

Инструмент для автоматической простановки реакций (эмодзи) на новые посты в выбранных Telegram-каналах.

---

## 🎯 Назначение
Используется для повышения вовлеченности (ER) на ваших каналах или для имитации активности живого пользователя при прогреве аккаунта.

## ⚙️ Как это работает
1. Модуль подключается к указанному списку каналов.
2. Получает последние посты в истории (или слушает новые).
3. Используя алгоритм рандомизации, проставляет случайные или заранее заданные реакции (👍, ❤️, 🔥 и т.д.).

## 🛠 Настройки
*   **Target Channels (Каналы):** Ссылки на каналы (например, `@durov`).
*   **Reaction Type:** Какие именно реакции ставить. Можно выбрать "Random" для большей естественности.
*   **Delay (Задержка):** Интервал между простановкой реакций (рекомендуется 5-15 секунд).

## 💡 Советы по использованию
- Не ставьте минимальную задержку! Telegram может заподозрить флуд.
- Используйте этот модуль вместе с `Channel Viewer` для максимальной реалистичности.
