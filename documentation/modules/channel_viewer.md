# 👀 Channel Viewer (Накрутка просмотров)

Модуль для асинхронного "просмотра" постов в каналах для накрутки метрики "Eye" (глазика).

---

## 🎯 Назначение
Создание видимости активности аудитории на ваших каналах. Повышает привлекательность канала для рекламодателей и алгоритмов Telegram.

## ⚙️ Как это работает
Модуль переходит в указанный канал, получает ID последних `N` постов и отправляет специальный API запрос `messages.getMessagesViews`, который засчитывает просмотр от лица аккаунта.

## 🛠 Настройки
*   **Channel Link:** Ссылка на публичный или приватный канал.
*   **Posts Count:** Количество последних постов, которые нужно "просмотреть".
*   **Scroll Delay:** Задержка между "пролистыванием" постов (в секундах).

## 💡 Советы по использованию
- Для приватных каналов аккаунт сначала должен подписаться на канал.
- Используйте прокси! Если 100 просмотров придут с одного IP, Telegram спишет их в течение суток.
