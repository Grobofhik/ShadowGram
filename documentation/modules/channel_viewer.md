# Накрутка просмотров

Модуль читает посты канала и вызывает Telegram API для увеличения просмотров.

## Параметры

- `channel_link`
- `post_limit`

## Особенности

- циклический модуль
- старт и повторы идут с большими случайными паузами
- принимает username, ссылку или numeric channel id
- при необходимости может вступить в канал
