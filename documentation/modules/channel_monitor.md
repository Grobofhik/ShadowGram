# Мониторинг канала 24/7

Циклический модуль для слежения за каналом.

## Параметры

- `channel_url`
- `check_interval`
- `do_views`
- `do_reactions`
- `reaction_chance`
- `do_comments`
- `comment_chance`
- `api_key`
- `api_base_url`
- `model_name`

## Что делает

- следит за каналом в цикле
- при новом посте может:
  - накрутить просмотры
  - поставить реакции
  - оставить AI-комментарии

Минимальный интервал проверки в коде ограничен.
