# Умный прогрев

Большой модуль для имитации живого поведения аккаунта.

## Параметры

- `chat_links`
- `use_bots`
- `reactions_chance`
- `write_chance`
- `api_key`
- `api_base_url`
- `model_name`
- `min_delay`
- `max_delay`

## Что делает

Внутри модуля есть набор бытовых действий:

- чтение каналов
- реакции
- пересылка в избранное
- работа с ботами
- обновление части профиля
- AI-общение в чатах
- прочие мелкие действия для естественного следа

Не обещай себе точный набор "24 тумблера" по UI. Ориентируйся на фактические параметры и код модуля.
