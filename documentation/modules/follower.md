# 📥 Mass Follower (Масс-Фолловер)

Инструмент для массовой подписки аккаунтов на целевые каналы или публичные группы.

---

## 🎯 Назначение
Используется для создания стартовой базы подписчиков на новых каналах, либо для подготовки аккаунтов к дальнейшему парсингу пользователей из этих групп.

## ⚙️ Как это работает
Модуль берет список ссылок, парсит ID каналов/групп и отправляет запрос `JoinChannel` / `JoinChat`. Алгоритм умеет обходить капчи базовых анти-спам ботов (решая простые математические задачи или нажимая inline-кнопки).

## 🛠 Настройки
*   **Target Links:** Ссылки на каналы (каждая с новой строки).
*   **Delay:** Задержка между подписками (в секундах). Рекомендуется: 30-120с.
*   **Batch Size:** Сколько подписок делать в рамках одной сессии, прежде чем уйти в спящий режим.

## 💡 Советы по использованию
- Telegram строго лимитирует количество подписок в день для одного аккаунта (около 20-30 подписок для старых аккаунтов и 5-10 для новых). Превышение этого лимита ведет к мгновенному `PeerFlood` (временный мут).
- Используйте приватные ссылки (содержащие `+` или `joinchat`), если публичная ссылка недоступна.
