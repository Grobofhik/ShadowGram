# 🔑 Get Auth Code (Получение кода)

Служебный модуль для извлечения кодов авторизации Telegram из активных сессий.

---

## 🎯 Назначение
Позволяет вам залогиниться в официальный клиент Telegram (на телефоне или ПК), используя купленную/зарегистрированную сессию в ShadowGram, без необходимости иметь доступ к физической сим-карте.

## ⚙️ Как это работает
1. Вы запрашиваете код авторизации в официальном клиенте Telegram.
2. Сервер Telegram отправляет этот код системным сообщением (от контакта `Telegram / 777000`) в вашу Tdata сессию.
3. Модуль проверяет историю чата с `777000` и извлекает из текста 5-значный код авторизации.

## 🛠 Настройки
Для запуска не требуются специфические настройки. Выберите аккаунт и нажмите кнопку "Запуск".

## 💡 Советы по использованию
- Если вы пытаетесь залогиниться с другого IP-адреса, Telegram может отказать во входе или потребовать дополнительный пароль (2FA). Убедитесь, что вы знаете пароль двухфакторной аутентификации, если он установлен.
