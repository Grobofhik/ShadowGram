# Получить номер телефона

Читает номер телефона прямо из локальной `.session` SQLite-базы.

## Особенности

- без подключения к Telegram
- очень быстро
- зависит от того, что номер сохранён в session/peers таблицах

## Когда полезно

- для инвентаризации старых аккаунтов
- когда сеть или proxy сейчас не нужны
