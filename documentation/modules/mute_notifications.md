# <img src="../../resources/icons/moduls_icon.png" width="32" valign="middle"> Mute All

Модуль для массового отключения уведомлений во всех чатах, группах и каналах. Идеально подходит для "тихого" прогрева аккаунтов или работы с большим количеством спам-каналов.

---

## 🛠 Функционал

1.  **Глобальное отключение:** Устанавливает настройки `Mute` по умолчанию для всех новых личных сообщений, групп и каналов.
2.  **Массовая обработка:** Проходит по всем существующим диалогам в аккаунте и отключает уведомления в каждом из них.
3.  **Бессрочный режим:** Уведомления отключаются "навсегда" (используется максимальное значение системного таймера).
4.  **Скрытый режим:** Устанавливает флаг `silent`, что предотвращает появление всплывающих окон и звуков.

---

## 🚀 Как использовать

1.  Выберите один или несколько аккаунтов в главном списке.
2.  Откройте окно **Модули** (<img src="../../resources/icons/moduls_icon.png" width="16" valign="middle">).
3.  Выберите из списка **🔕 Mute All**.
4.  Нажмите кнопку **Запустить**.

---

## ⚠️ Особенности работы

*   **Лимиты Telegram:** Если на аккаунте очень много чатов (сотни или тысячи), процесс может занять некоторое время из-за пауз, предотвращающих `FloodWait`.
*   **Новые чаты:** Благодаря обновлению глобальных настроек, уведомления в новых чатах, в которые вы вступите позже, также будут отключены по умолчанию.
*   **Исключения:** Модуль отключает всё. Если вам нужны уведомления в конкретном чате, их придется включить вручную после работы модуля.
