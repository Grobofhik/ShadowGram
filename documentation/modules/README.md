# 🧩 Модули ShadowGram

Модули — это мощные плагины, расширяющие базовый функционал ShadowGram. Каждый модуль выполняет определенный алгоритм действий для автоматизации работы с вашими сессиями.

---

## 🚀 Как запускать модули?

1. Перейдите во вкладку **Модули** на левой боковой панели.
2. В таблице **"Доступные аккаунты"** отметьте галочкой те профили, для которых вы хотите запустить задачу. Вы можете нажать **"Выбрать всё"** для массового запуска.
3. В списке модулей кликните на нужный вам скрипт (например, *Privacy Guard* или *Smart Warmer*).
4. Заполните необходимые настройки в появившейся форме (ссылки, задержки, параметры).
5. Нажмите кнопку **▶ Запустить**.

> 💡 **Архитектура запуска:** Каждый аккаунт запустит модуль в собственном независимом потоке. Это гарантирует полную изоляцию и высокую скорость выполнения даже для сотен аккаунтов одновременно!

## 📦 Доступные категории

В системе присутствуют модули для различных задач:
- **Прогрев (Warming):** Имитация живого человека (Smart Warmer, Auto Reactor).
- **Продвижение:** Накрутка просмотров, массовые подписки, комментирование.
- **Менеджмент:** Проверка сессий, массовая установка аватарок, изменение настроек приватности.

Выберите нужный раздел в боковом меню документации для получения подробной инструкции по конкретному модулю.
