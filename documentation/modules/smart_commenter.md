# Нейрокомментинг

Продвинутый модуль автоматических комментариев в реальном времени.

## Что делает

- следит за новыми постами
- генерирует комментарии
- старается действовать мягче, чем прямой спам-комментер

## Когда использовать

- для живых каналов, где важна скорость реакции
- после базового прогрева аккаунтов
