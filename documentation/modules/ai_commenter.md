# AI-комментер

Плагин читает посты в канале и пытается оставить AI-комментарии в discussion chat.

## Параметры

- `channel_url`
- `api_key`
- `api_base_url`
- `model_name`
- `posts_count`
- `comment_chance`

## Особенности

- если у аккаунта есть `ai_prompt`, используется он
- если `api_key` пустой и prompt содержит spintax, возможен spintax-режим без внешнего AI
- при необходимости аккаунт может вступить в discussion chat
- имитирует typing delay

## Когда использовать

- для мягкого контентного прогрева
- для живых комментариев под постами
