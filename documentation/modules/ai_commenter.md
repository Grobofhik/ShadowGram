# 🤖 AI Commenter (Нейро-комментатор)

Автоматизирует процесс написания осмысленных комментариев под постами в каналах с использованием нейросетей (OpenAI / GPT).

---

## 🎯 Назначение
Привлечение трафика из комментариев крупных каналов, партизанский маркетинг или просто создание видимости бурного обсуждения.

## ⚙️ Как это работает
1. Модуль мониторит появление нового поста в канале.
2. Отправляет текст поста в API нейросети с заданным промптом (например: *"Напиши короткий, соглашающийся комментарий"*).
3. Публикует ответ от лица вашего аккаунта в секции комментариев.

## 🛠 Настройки
*   **OpenAI API Key:** Ваш ключ для генерации текста.
*   **Target Channels:** Список каналов для мониторинга.
*   **Prompt System:** Инструкция для нейросети (какой тон использовать, использовать ли эмодзи).
*   **Delay:** Задержка перед отправкой (имитация набора текста).

## 💡 Советы по использованию
- Добавляйте задержку в 10-30 секунд после выхода поста, чтобы ваш комментарий не выглядел как ответ бота (первонаха).
