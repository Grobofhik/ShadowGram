# Первый запуск

## Что делает приложение при старте

При первом запуске `ShadowGram.py`:

- создаёт базовый `config.json`, если его нет
- инициализирует структуру `farms/`
- создаёт или выбирает активную ферму
- зеркалит данные в SQLite через `db_manager`
- при включённом PIN просит код входа в приложение

## Минимальная подготовка

Нужно иметь:

- Python-окружение с зависимостями
- рабочий `PyQt6`
- `hydrogram`
- `telethon`, если нужен Telethon flow
- `gost`, если будут HTTP/HTTPS proxy

## После запуска

Рекомендуемый порядок:

1. Открой `Настройки`.
2. Заполни `default_tg_api_id` и `default_tg_api_hash`.
3. При необходимости задай AI API key/base URL/model.
4. Добавь proxy pool или прокси вручную по аккаунтам.
5. Создай профиль.
6. Нажми `Авторизовать (Войти)` и создай сессию.

## Если уже есть данные

Можно:

- импортировать ZIP backup
- переключиться на другую ферму
- открыть готовые профили, если они уже лежат в `farms/<farm>/accounts`
