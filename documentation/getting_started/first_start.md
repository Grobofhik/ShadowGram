# 🚀 Первый старт (Быстрый старт)

Добро пожаловать в ShadowGram! Если вы открыли программу впервые, вам необходимо выполнить базовую настройку, чтобы получить возможность авторизовывать аккаунты.

Следуйте этой пошаговой инструкции.

---

## 🔑 Шаг 1. Получение API ID и API Hash

ShadowGram общается с серверами Telegram напрямую через протокол MTProto. Для этого необходимы ключи разработчика.

1. Перейдите на официальный сайт Telegram для разработчиков: [my.telegram.org](https://my.telegram.org)
2. Авторизуйтесь с помощью вашего личного (основного) номера телефона.
3. Выберите раздел **"API development tools"**.
4. Заполните короткую форму:
   - *App title:* Любое название (например, `ShadowClient`)
   - *Short name:* Любое короткое слово (например, `shadowcl`)
   - *Platform:* Выберите `Desktop` или `Other`
5. После сохранения вы увидите два значения: **App api_id** (только цифры) и **App api_hash** (строка из букв и цифр). Сохраните их!

---

## ⚙️ Шаг 2. Ввод глобальных настроек

Теперь нужно передать полученные ключи в программу.

1. В левом боковом меню ShadowGram перейдите во вкладку **Настройки**.
2. В секции "Telegram API" вставьте ваш **API ID** и **API Hash**.
3. (Опционально) Установите ПИН-код для защиты входа в программу.
4. Нажмите кнопку **"💾 Сохранить все настройки"** в самом низу.
> *Эти ключи станут "глобальными" и будут использоваться для всех новых профилей по умолчанию.*

---

## 👤 Шаг 3. Создание первого профиля

Теперь мы готовы добавить ваш первый аккаунт в базу.

1. Перейдите во вкладку **Аккаунты** (самая первая иконка в меню).
2. В нижней панели найдите секцию **"Добавить новый профиль"**.
3. Заполните поля:
   - **Имя профиля:** Любое понятное имя (например, `Main_Worker_1`).
   - **Путь к Tdata/Папке:** Нажмите на иконку папки и создайте новую пустую папку на вашем компьютере (например, `C:\ShadowSessions\Worker_1`). В ней будут храниться файлы сессии.
   - **HTTP Proxy:** Опционально. Если у вас есть прокси, введите его в формате `http://user:pass@ip:port`.
4. Нажмите кнопку **"Создать"**. Профиль появится в таблице выше!

---

## 📲 Шаг 4. Авторизация аккаунта (Логин)

Аккаунт создан, но он пуст. Нам нужно "войти" в Telegram.

1. В левом боковом меню перейдите во вкладку **Модули**.
2. Поставьте галочку напротив вашего нового аккаунта в таблице "Доступные аккаунты".
3. В списке модулей (справа) выберите любой базовый модуль, например, **Проверка сессии** (Check Session).
4. Нажмите **Запуск**.
5. Так как сессия в папке еще не создана, ShadowGram обнаружит это и **откроет окно авторизации**.
6. Введите номер телефона привязываемого аккаунта.
7. Введите код подтверждения (он придет вам в официальный клиент Telegram или по СМС).
8. Если аккаунт защищен 2FA-паролем, программа запросит и его.

🎉 **Готово!** Аккаунт успешно авторизован, сессия сохранена в выбранной вами папке, и теперь вы можете использовать любые модули для автоматизации!
