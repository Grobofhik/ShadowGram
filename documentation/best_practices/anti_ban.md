# Антибан-практика

## Что реально помогает

- живые и стабильные proxy
- свои `api_id/api_hash`
- умеренные задержки
- разный device/app metadata по аккаунтам
- постепенный прогрев новых сессий
- не делать много одинаковых действий одновременно

## Что уже умеет проект

- `stealth_mode` увеличивает паузы
- модули используют sleep-диапазоны, а не одну жёсткую цифру
- `Умный прогрев` делает поведение менее однотипным
- `Проверка сессии` помогает быстро отсеять битые аккаунты

## Чего не делать

- не использовать один proxy на слишком много аккаунтов
- не запускать десятки аккаунтов на один канал без пауз
- не надеяться на fallback API как на постоянное решение
- не ломать руками структуру `farms/<farm>/accounts`
- не хранить backup со сессиями в небезопасном месте

## Для новых аккаунтов

Безопасный старт:

1. Создай сессию.
2. Пройди `Privacy Guard`.
3. Пройди `Mute All`.
4. Прогрей аккаунт.
5. Только потом запускай агрессивные сценарии.
