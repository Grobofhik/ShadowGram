# ⚙️ Глобальные настройки ShadowGram

Вкладка **Настройки** содержит ключевые параметры, которые влияют на поведение всего приложения. Внесенные изменения автоматически сохраняются в файл `config.json` и применяются ко всем новым и существующим сессиям (где это применимо).

---

## 🔑 Telegram API
Для взаимодействия с серверами Telegram приложению требуются идентификаторы разработчика.
- **Default API ID / API Hash:** Введите ключи, полученные на `my.telegram.org`. Эти ключи будут автоматически использоваться для всех новых аккаунтов, если при их создании вы оставите поля API пустыми. 
- *Рекомендация:* Для крупных ферм используйте индивидуальные ключи для каждого аккаунта, чтобы избежать массовых банов (Фродинг приложения).

## 🛡 Безопасность и Доступ
ShadowGram предоставляет встроенные механизмы защиты вашей фермы от несанкционированного доступа.
- **Защита ПИН-кодом:** Активируйте тумблер и задайте цифровой код. При каждом следующем запуске ShadowGram будет требовать этот ПИН-код до показа графического интерфейса.
- **Экстренная очистка кэша:** Включите **Auto-Clean Cache**, чтобы при выходе из приложения автоматически удалялись временные файлы логов и медиа-кэш из всех рабочих директорий.

## 💾 Резервное копирование (Backups)
Управление десятками аккаунтов требует надежной системы сохранения данных.
- **Автоматические бекапы при выходе:** Если включено, при каждом закрытии ShadowGram система будет собирать все папки сессий, `config.json` и логи в один `.zip` архив.
- Архивы сохраняются в папку `backups/` в корне проекта с указанием даты и времени.

## 📡 Сеть и Тайм-ауты
Тонкая настройка сетевых подключений для стабильной работы модулей через прокси.
- **Network Timeout:** Максимальное время ожидания ответа от серверов Telegram (в секундах). Рекомендуется увеличивать этот параметр (до 30-60с) при использовании медленных IPv6 прокси.

## 🔔 Уведомления и Системный трей
ShadowGram интегрирован в системный лоток (System Tray) вашей операционной системы.
- **Уведомления об окончании работы:** Приложение пришлет Push-уведомление, когда модуль завершит массовую рассылку или проверку.
- **Уведомления о блокировках:** Мгновенный алерт в случае, если сессия получает статус `BANNED`.
- **Звуковые оповещения:** Воспроизведение системного звука при критических ошибках.
