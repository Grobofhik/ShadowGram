# <img src="../../resources/icons/settings_icon.png" width="32" valign="middle"> Глобальные настройки ShadowGram

В этом разделе описаны возможности вкладки "Настройки", которая позволяет централизованно управлять параметрами работы вашей фермы аккаунтов.

---

## <img src="../../resources/icons/server_icon.png" width="24" valign="middle"> 1. API & AI
Здесь настраиваются ключи, необходимые для работы с Telegram API и нейросетями:
*   **API ID / API Hash**: Ваши уникальные ключи от `my.telegram.org`.
*   **AI API Ключ**: Токен для сервиса нейросетей (например, Groq или OpenRouter).
*   **AI Base URL**: Адрес сервера нейросети.
*   **AI Название модели**: Модель, которая будет генерировать тексты (например, `llama-3.1-8b-instant`).

Эти данные подставляются автоматически в поля плагинов (например, AI Commenter).

---

## <img src="../../resources/icons/moduls_icon.png" width="24" valign="middle"> 2. Автоматизация
Раздел для управления задержками и лимитами, защищающий вашу ферму от блокировок:

*   **Задержка между запусками Telegram**: Время (в секундах) между открытием окон Telegram при массовом запуске из главного меню. Спасает процессор от перегрузки.
*   **Макс. ожидание FloodWait**: Лимит времени (в секундах), который плагин готов ждать, если Telegram выдал временное ограничение. `0` — ждать всегда.
*   **Максимум одновременных задач**: Лимит конкурентности. Если у вас 100 аккаунтов, а лимит 10, то одновременно будут работать только 10 сессий, остальные будут ждать своей очереди.
*   **Режим Невидимки (Stealth Mode)**: Секретная функция! При включении галочки **все задержки во всех плагинах автоматически увеличиваются на 50%**. Это делает поведение ботов еще более плавным и "человечным".

---

## <img src="../../resources/icons/proxy_icon.png" width="24" valign="middle"> 3. Прокси Пул
Мощный инструмент для массовой работы с прокси:
*   Вставьте список ваших прокси (каждый с новой строки) в текстовое поле.
*   **Кнопка "Проверить весь пул"**: Пропингует каждый прокси из списка в многопоточном режиме и удалит нерабочие (мертвые) IP.
*   **Кнопка "Распределить прокси по аккаунтам"**: Возьмет проверенный пул и равномерно (по кругу) раздаст прокси всем вашим созданным аккаунтам.

---

## <img src="../../resources/icons/cash_icon.png" width="24" valign="middle"> 4. Данные и Обслуживание
Управление кэшем и логами для экономии места на диске:
*   **Автоматически чистить кэш**: При закрытии сессии Telegram, программа сама удалит папки с закэшированными фото и видео.
*   **Ротация логов**: Настройка позволяет автоматически очищать старые файлы логов (`telegram_error.log`, `gost_module.log`), которые старше указанного количества дней. Вы также можете запустить очистку вручную кнопкой **"Очистить устаревшие логи сейчас"**.
*   **Глубокая очистка кэша всей фермы**: Моментально проходит по всем папкам аккаунтов и удаляет скопившийся "мусор".
*   **Импорт нового модуля (.py)**: Позволяет добавить сторонний плагин в программу прямо из файла. Просто выберите файл, и он скопируется в папку с плагинами.

---

## <img src="../../resources/icons/view_icon.png" width="24" valign="middle"> 5. Интерфейс
*   **Компактный режим**: Уменьшает высоту строк в главном списке аккаунтов, что позволяет уместить больше сессий на одном экране без прокрутки.

---

## <img src="../../resources/icons/save_icon.png" width="24" valign="middle"> 6. Бэкапы
*   **Экспорт всех данных (ZIP)**: Создает единый архив, в который упаковывается файл `config.json` и все папки с сессиями Telegram. Отличный способ перенести ферму на VPS (ServerGram) или сделать резервную копию.
*   **Импорт из бэкапа (ZIP)**: Распаковывает архив и полностью восстанавливает список аккаунтов. Внимание: текущие данные будут перезаписаны!
