# Глобальные настройки

## Вкладка `API & AI`

- `default_tg_api_id`
- `default_tg_api_hash`
- `default_ai_api_key`
- `default_ai_api_base_url`
- `default_ai_model`
- persona prompt для AI

Эти Telegram-ключи используются как дефолт для новых профилей и как второй источник для auth, если у аккаунта своих ключей нет.

## Вкладка `Автоматизация`

- задержка между запусками Telegram
- максимальный `FloodWait`, который проект готов пережидать
- максимум параллельных задач модулей
- сетевой timeout
- `stealth_mode`

`stealth_mode` увеличивает паузы и делает поведение модулей мягче.

## Вкладка `Пул Прокси`

Можно:

- добавлять proxy pool
- проверять pool
- удалять мёртвые прокси
- раздавать pool по аккаунтам
- очищать pool

## Вкладка `Аккаунты & Прокси`

Таблица для массовой правки proxy профилей:

- редактирование
- очистка конкретных proxy
- полный reset proxy по всем аккаунтам

## Вкладка `Обслуживание`

- `auto_clean_cache`
- очистка старых логов
- deep clean cache активной фермы
- импорт внешнего python-модуля в систему плагинов

## Вкладка `Интерфейс`

- тема `Cyber Green` или `Deep Blue`
- compact mode

## Вкладка `Бэкапы`

- `auto_backup` при выходе
- export ZIP
- import ZIP

Экспорт включает `config.json` и найденные файлы сессий/аватаров аккаунтов.

## Вкладка `Безопасность`

- включение PIN на запуск
- уведомления
- звуковые alerts

## Вкладка `Фермы`

- активная ферма
- переключение фермы
- создание новой фермы

Новая ферма копирует текущие настройки, но не аккаунты.
